## Vaseis.info

A web application for Greek university candidates to compare entry grades between schools, track which schools' grades increase or decrease over time, and make informed decisions.

[Visit Vaseis.info](https://www.vaseis.info)

## AthensBus.info

An open source application that allows Athens bus users to see what trips bus routes made each day and compare the official itinerary with the actual trips.

[Visit AthensBus.info](https://www.athensbus.info)
